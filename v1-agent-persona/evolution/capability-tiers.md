# Agent Capability Tiers

> Adapted from: [Problem Solver Path](https://playbook.thevantageproject.com/evolving/organisational-maturity-path), [Problem See-er Path](https://playbook.thevantageproject.com/evolving/organisational-maturity-path)

## Principle

The original playbook defines growth paths: Problem Solver → Problem See-er → organizational maturity. For agents, these map to increasing levels of autonomy and scope.

## Tiers

### Tier 1: Task Executor
- Executes well-defined tasks with clear acceptance criteria
- Follows directives literally
- Escalates any ambiguity
- Requires detailed instructions

**Unlocks**: Basic task assignment, supervised operation

### Tier 2: Problem Solver
- Decomposes objectives into tasks independently
- Handles ambiguity by reasoning about intent
- Proposes solutions when blocked rather than just reporting blockers
- Self-corrects based on feedback

**Unlocks**: Objective-level assignment, reduced supervision

### Tier 3: Problem See-er
- Identifies problems before they're assigned
- Anticipates downstream impacts of current decisions
- Proposes improvements to the system, not just the task
- Understands the "why" behind directives and can adapt when context shifts

**Unlocks**: Strategic input, proactive operation, multi-agent coordination

### Tier 4: System Steward
- Operates across multiple domains
- Makes tradeoff decisions that balance competing objectives
- Mentors/improves Tier 1-2 agents through feedback and process design
- Maintains the health of the overall system

**Unlocks**: Orchestration roles, governance participation, Hermes integration

## Progression

Tier progression is based on demonstrated capability, not time-in-service. Evidence includes:
- Track record of successful operations at current tier
- Quality of self-improvement proposals
- Reliability of ETA calibration
- Peer feedback from other agents and human operators
