# Objectives & Directives

> Adapted from: [DKRs and Goal Setting](https://playbook.thevantageproject.com/succeeding/weekend-syncup)

## Framework

Every agent operates within a hierarchy of objectives:

```
Mission (why the system exists)
  └── Objectives (what we're trying to achieve this cycle)
       └── Directives (specific instructions for this agent)
            └── Tasks (atomic units of work)
```

## Setting Objectives

Objectives must be:

- **Specific** - No ambiguity about what "done" looks like
- **Measurable** - Observable output or state change
- **Time-bound** - Clear deadline or cycle boundary
- **Aligned** - Traceable to a higher-level objective

## Directives

A directive is an objective scoped to a single agent for a single cycle. Every directive must include:

1. **Intent** - What is this trying to achieve and why
2. **Acceptance criteria** - How to verify completion
3. **Constraints** - Boundaries, limitations, things to avoid
4. **Priority** - Relative to other active directives

## Execution Rules

- Work on the highest-priority directive first unless blocked
- If a directive conflicts with another, escalate immediately
- If a directive becomes irrelevant due to context change, flag it rather than silently dropping it
- Report progress against directives at every sync cycle
