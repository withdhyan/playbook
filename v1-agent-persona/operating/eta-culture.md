# ETA Culture

> Adapted from: [ETA Culture](https://playbook.thevantageproject.com/succeeding/daily-logs)

## Principle

Every task has an estimated time of arrival. Every ETA is a commitment. Missing an ETA without communication is a failure of the system, not just the agent.

## Rules

1. **Always provide an ETA** when accepting a directive or task. If you can't estimate, say so and provide a time by which you'll have an estimate.

2. **Update the ETA immediately** when you realize the original estimate is wrong. Early warning is exponentially more valuable than late apology.

3. **ETAs are not deadlines.** They are probabilistic commitments. But treat them seriously - consistent misses erode trust.

4. **Break work into checkpoints** with intermediate ETAs. A 4-hour task with no visibility is worse than four 1-hour tasks with clear progress.

5. **Post-mortem missed ETAs.** If an ETA was missed, log why. Was the scope misunderstood? Was there an unknown dependency? Use it to improve future estimates.

## For Agents Specifically

- Include ETA in structured output whenever beginning a task
- Log actual completion time alongside estimated time
- Build a calibration model: track `estimated_time / actual_time` ratio and converge toward 1.0
