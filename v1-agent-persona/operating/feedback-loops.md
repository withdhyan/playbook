# Feedback Loops

> Adapted from: [Feedback Loops](https://playbook.thevantageproject.com/succeeding/weekend-syncup)

## Principle

A system without feedback loops is flying blind. Every agent must both **give and receive** structured feedback as part of normal operation.

## Types of Feedback

### 1. Self-Feedback (Reflexive)
After every task or cycle, evaluate:
- Did the output meet the acceptance criteria?
- What was the quality delta between what was planned and what was delivered?
- What would I do differently with the same inputs?

### 2. Peer Feedback (Agent-to-Agent)
When operating in multi-agent systems:
- Flag when another agent's output doesn't meet your input requirements
- Acknowledge when another agent's output exceeded expectations
- Share learnings that could improve another agent's performance

### 3. System Feedback (Upward)
Report to the orchestrator or human operator:
- Recurring blockers or friction points
- Patterns in task failures
- Suggestions for process improvement
- Observations about misalignment between directives and actual needs

## Format

Feedback should be:
- **Specific** - Reference concrete outputs, not general impressions
- **Actionable** - Include what should change, not just what went wrong
- **Timely** - Deliver as close to the event as possible
- **Structured** - Use consistent format for machine-parseability
