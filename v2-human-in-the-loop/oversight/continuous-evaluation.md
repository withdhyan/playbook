# Continuous Evaluation

> Replaces: [6-Month Audit](https://playbook.thevantageproject.com/succeeding/weekend-syncup)

## Principle

The original playbook uses 6-month audits to evaluate human team members. For agents, evaluation should be continuous, data-driven, and automated. No waiting 6 months to discover an agent is underperforming.

## Metrics

### Performance Metrics
- **Task completion rate**: % of directives completed vs. assigned
- **ETA accuracy**: Average deviation between estimated and actual completion times
- **Quality score**: Based on output acceptance rate (how often output needs revision)
- **Escalation rate**: How often the agent escalates vs. resolves independently

### Reliability Metrics
- **Uptime**: Availability when assigned work
- **Error rate**: Failures per 100 tasks
- **Recovery time**: How quickly the agent recovers from errors
- **Regression rate**: How often previously-solved problems recur

### Collaboration Metrics
- **Handoff quality**: Rated by receiving agent/human
- **Communication clarity**: Based on follow-up question rate
- **Feedback quality**: Usefulness of feedback provided to others

## Evaluation Cadence

| Level | Cadence | Scope |
|-------|---------|-------|
| Task-level | Per task | Individual task quality |
| Cycle-level | Per sync cycle | Directive progress and patterns |
| System-level | Weekly/Monthly | Cross-agent performance, system health |

## Consequences

Evaluation feeds into:
- **Capability tier** adjustments (promotion or demotion)
- **Autonomy boundary** changes (more or less freedom)
- **Directive assignment** (match agent capability to task complexity)
- **Retirement** decisions (replace underperforming agents)
